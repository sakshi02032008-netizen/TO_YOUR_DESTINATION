
# To Your Destination

## Project Overview
To Your Destination is a responsive travel agency website
created using HTML5 and CSS3. It helps visitors explore
destinations, view tour packages and submit travel inquiries.

## Features
- Attractive homepage and hero banner
- Popular travel destinations
- Tour package cards with prices
- Travel itinerary section
- Customer reviews and testimonials
- Travel inquiry form
- Responsive layout
- CSS animations and hover effects

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Google Fonts

## Project Structure
- index.html – Website structure
- style.css – Website styling
- images/ – Image assets
- README.md – Project documentation

## Responsive Breakpoints
- Desktop: Above 1024px
- Tablet: 768px to 1024px
- Mobile: Below 768px
- Small Mobile: Below 480px
